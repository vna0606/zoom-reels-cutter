# Zoom Reels Cutter

Режет длинные записи Zoom-эфиров на короткие вертикальные ролики (Reels / Shorts / TikTok).

- Распознаёт речь: облако Deepgram или локальный faster-whisper (бесплатно, медленнее).
- ИИ (Claude) собирает ролики по смыслу: карта тем, цельные мысли в естественном порядке речи, критик, главный редактор, поиск пропущенных моментов, подрезка пауз и слов-паразитов.
- Режим **broadcast**: вырезает активных спикеров Zoom и добавляет анимированную графику (HyperFrames). Режим **podcast**: вертикальный кадр по лицу, без графики.
- Проверяет готовые ролики по смыслу и звуку и складывает всё в галерею `index.html` + `report.json`.
- Всё работает на вашем компьютере; наружу уходят только текст/аудио для распознавания (если включён Deepgram) и запросы к ИИ.

> Подробное описание пайплайна — в [docs/PIPELINE.md](docs/PIPELINE.md).

## Что нужно

- Mac (Apple Silicon или Intel) **или** Windows 10/11 (64-бит).
- Около 5 ГБ свободного места и интернет (при установке скачиваются Python, FFmpeg, Node.js, Chromium).
- **Подписка Claude и установленный Claude Code** с выполненным входом (`claude auth login`). Установщик его не ставит, но подскажет, как это сделать.
- По желанию — ключ [Deepgram](https://console.deepgram.com/) (быстрее и точнее распознаёт речь). Без ключа автоматически используется локальный faster-whisper.

## Установка (3 шага)

1. Скачайте проект: `git clone https://github.com/vna0606/zoom-reels-cutter.git` или на GitHub «Code → Download ZIP» и распакуйте (на Windows лучше в короткий путь без кириллицы, например `C:\zoom-reels-cutter`).
2. Дважды щёлкните **«Установить (Mac).command»** или **«Установить (Windows).cmd»**. Установка занимает 10–20 минут, повторный запуск безопасен. В конце установщик сообщит, найден ли Claude Code.
   - Mac: если система не даёт открыть файл, щёлкните по нему правой кнопкой → «Открыть». Если файл не запускается как программа, выполните в Терминале в папке проекта: `chmod +x *.command *.sh`.
   - Windows: если SmartScreen предупреждает, нажмите «Подробнее → Выполнить в любом случае».
3. (Необязательно) Скопируйте `.env.example` в `.env` и впишите ключ после `DEEPGRAM_API_KEY=`.

> **Windows-установщик (`setup_windows.ps1`) пока не проверен на реальной машине** — он написан по аналогии с Mac-версией. Если что-то пошло не так, пришлите текст ошибки из окна установки.

## Запуск

- **Через интерфейс:** дважды щёлкните **«Запустить (Mac).command»** / **«Запустить (Windows).cmd»**. В браузере откроется `http://127.0.0.1:8765` — перетащите видео, выберите режим и нажмите запуск.
- **Через командную строку** (из папки проекта):

  ```bash
  .venv/bin/python run_reels.py "путь/к/эфиру.mp4"            # Mac
  .venv\Scripts\python.exe run_reels.py "C:\путь\к\эфиру.mp4"   # Windows
  ```

**Где результат.** CLI: папка `results/<имя-видео>/` рядом с программой — откройте `index.html` (галерея роликов), там же `report.json`, `run.log` и папка `rejected/` с отсеянными кандидатами. Веб-интерфейс: папка `workspace/` (ссылки на скачивание — в самом интерфейсе).

**Сколько времени.** Замер на MacBook Air M2 (8 ГБ), часовой эфир, Deepgram: распознавание ~2–10 минут, смысловой монтаж ~15 минут, затем рендер и отсмотр роликов. В режиме `podcast` это около 1 часа 15 минут на ~30 роликов. В режиме `broadcast` графика добавляет 3–5 минут на каждый ролик, то есть для ~30 роликов ещё около 2 часов. Без Deepgram (локальный Whisper) — плюс около часа на распознавание. Запуск можно прервать и повторить с той же `--out` — он продолжит с места остановки.

## Режимы и параметры

| Параметр | Значения | Что делает |
|---|---|---|
| `--mode` | `broadcast` (по умолчанию), `podcast` | broadcast: спикеры Zoom + графика; podcast: кадр по лицу, без графики |
| `--speakers` | `1`, `2` (по умолчанию 2) | сколько спикеров показывать в broadcast |
| `--asr` | `auto`, `deepgram`, `local` | распознавание: auto = Deepgram, если есть ключ |
| `--no-review` | флаг | не отсматривать готовые ролики (быстрее) |
| `--min` / `--max` | секунды (30 / 90) | длительность ролика |
| `--out` | папка | куда сложить результат |

Модель Claude: `opus` по умолчанию (лучшее качество); `sonnet` быстрее и меньше расходует лимиты — задайте `REEL_CLAUDE_MODEL=sonnet` в `.env`. Все параметры: `run_reels.py --help`.

## Если что-то не работает

1. **«Claude CLI не найден / не авторизован».** Установите Claude Code (Mac: `curl -fsSL https://claude.ai/install.sh | bash`; Windows: `irm https://claude.ai/install.ps1 | iex`, нужен Git for Windows), затем выполните `claude auth login` и запустите заново.
2. **Установка прервалась** (нет интернета, закончилось место). Просто запустите установщик ещё раз — он продолжит с того же места.
3. **Страница http://127.0.0.1:8765 не открывается.** Снова запустите «Запустить…». Причина ошибки — в файле `server.err.log` в папке проекта. Если порт 8765 занят другой программой, закройте её.
4. **Субтитры без текста / квадратики.** Не найден шрифт Arial: перезапустите установщик (он копирует Arial в `.tools/fonts`) или укажите свою папку в переменной `REEL_FONTS_DIR`.
5. **Распознавание очень долгое.** Без ключа Deepgram работает локальный Whisper на процессоре. Добавьте ключ в `.env` или запустите с `--no-review`.
6. **Ошибка Deepgram (401 / нет ключа).** Проверьте ключ в `.env` (строка `DEEPGRAM_API_KEY=...` без кавычек и пробелов) или запустите с `--asr local`.
7. **Windows: «путь слишком длинный» или странные ошибки.** Переместите папку в `C:\zoom-reels-cutter` и повторите установку.

## Для разработчиков

Тесты: `.venv/bin/python -m unittest discover -s tests` (Windows: `.venv\Scripts\python.exe -m unittest discover -s tests`). Структура: `reel_factory/` — ядро (`editorial.py`, `assembly.py`, `broadcast.py`, `review.py`, ...), `hyperframes/broadcast-motion/` — шаблон графики, `web/` + `app.py` — интерфейс.
